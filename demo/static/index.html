Privacy: uploaded traces are parsed in memory and never written to disk, stored, or logged — the server renders your report and forgets you (read the code). No signup, no cookies, no analytics. tokenaudit itself reads hashes and token counts, not prompt text. Reports are static HTML with no scripts.
