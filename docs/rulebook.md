## anthropic

TTL semantics: **from_request_start** · accounting: **exclusive** · verified 2026-11-10 · [source](https://platform.claude.com/docs/en/build-with-claude/prompt-caching)

Minimum cacheable length is model-tiered and does not track model size. Automatic caching takes one of the four breakpoint slots. A breakpoint looks back at most 20 positions, itself included; a run of tool_use or tool_result blocks counts as one. TTL runs from the start of the request that wrote or last read the entry. Reads bill at 0.1x except Opus/Sonnet 5.5 (0.05x) and Fable/Mythos 5.1-5.2 (0.025x). Values are for the Claude API; Bedrock publishes its own. Usage fields are exclusive: total input = input_tokens + cache_read_input_tokens + cache_creation_input_tokens.

## google

TTL semantics: **?** · accounting: **nested** · verified 2026-11-10 · [source](https://ai.google.dev/gemini-api/docs/caching)

Implicit caching is on by default for Gemini 2.5 and newer. Explicit caches exist only through generateContent on Gemini 3 and 2.5, not in the Interactions API or on Gemini 4, so 'you never created a cache' is not a valid finding there. On Gemini 4, a turn that adds fewer than 2,050 tokens re-processes the last 2,050 tokens of the previous request at the standard rate. Cached tokens appear as usage.total_cached_tokens. TTL and discount are not published, so they are null.

## openai

TTL semantics: **sliding_from_last_use** · accounting: **nested** · verified 2026-11-10 · [source](https://developers.openai.com/api/docs/guides/prompt-caching)

Automatic, prefix-based caching. GPT-5.6 and later: 1,024-token minimum, explicit breakpoints (up to four cache writes per request, the automatic one included), and a 30m or 12h minimum lifetime. Earlier models: the minimum varies with request settings, writes cost nothing extra, retention is in_memory (about 5-10 min idle, up to 1h) or 24h, and cached_tokens rounds down to a multiple of 128. Invalidated by changes to model, tools (including order), parallel_tool_calls, text.format, reasoning.effort, text.verbosity or context_management. prompt_cache_key affects routing before 5.6. Usage is nested: input_tokens_details.cached_tokens (and cache_write_tokens on 5.6+) are counted inside input_tokens.
